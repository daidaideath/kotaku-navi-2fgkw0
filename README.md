# 個タク準備ナビ

個人タクシー開業を考えている人向けの準備ボード。いくつかの質問に答えると、準備の段階・やること・学習計画ができ、学習クイズ「個タクQUIZ」も解けます。

- 開業できるかどうかの判定ではなく、準備の順番の目安です。条件は関東運輸局の公式資料で確認してください。
- 名前や生年月日は聞きません。

## 記録の保存先

同じファイルが、開く場所によって2通りに動きます（`index.html` 末尾の起動処理で切り替え）。

| | 共有用 | 本人用 |
|---|---|---|
| 開く場所 | claude.ai 以外（GitHub Pages など） | claude.ai 上（保存領域 `db` が使えるとき） |
| 保存先 | その端末のブラウザー（localStorage）。サーバーへは送信しません | claude.ai の保存領域。PC・iPad・iPhoneで同期 |
| 控え | 設定 →「控えのコード」をコピー／貼り付けで戻す | 設定 →「控えをJSONで保存」 |
| 本人情報の欄 | なし | あり（相談シートには出ません） |
| 見た目 | 紺のヘッダー・「共有用」の札・「Q」のマーク。アイコンは白地に「個人」 | 紫のヘッダー・「本人用」の札・「本」のマーク。アイコンは青地に「本人」。タブ名は「個タク準備ナビ（本人用）」 |

## ファイル

- `index.html`：画面と処理（質問・ホーム・準備・過去問の記録・相談シート・設定）
- `kotaku-learn.js`：学習教材（「学ぶ」とクイズ）。教材の正本
- `icon-180.png`・`icon-me-180.png`：タブとホーム画面のアイコン（共有用は白地に青の表示灯と「個人」、本人用は青地に「本人」）
- `tools/smoke-test.js`：動作確認スクリプト
- `.nojekyll`：GitHub Pages でそのまま配信するための空ファイル

PDF・PNG の出力には外部の CDN（cdnjs）から html2canvas と jsPDF を読み込みます。読み込めないときは「LINE用の文章をコピー」だけ使えます。

## 更新するとき

**学ぶの項目を公開する**（`kotaku-learn.js`）

1. `SESSIONS` に回を足す（会話・予想の問題・説明・確認の問題）。根拠は `SRC` の公式資料・法令（e-Gov法令検索）で本文を確かめたものだけにし、回に `checked`（確認日）を付ける。カードと○×問題にも同じ確認日が表示される
2. `ITEMS` の該当する項目に `sid`（回の番号）を付ける。`sid` のない項目は「準備中」と表示される
3. `CARDS[回の番号]` に覚えるカード、`OX` に○×問題を足す
4. `ORDER`（おすすめの順番）に項目の id を足す。「次に読む」と前後ボタンはこの順番で進む
5. 本文に「（準備中）」と書いた箇所（`REWORD`）があれば直す

**制度の確認日を更新する**：公式資料を確かめ直したら、次の日付を直す。

- `index.html` の `CHECKED`
- `kotaku-learn.js` の `CHECKED`（最初の6項目の説明・予想・確認の問題）、`CARD_CHECKED`（最初の6項目のカード・○×）、`ADDED_CHECKED`（2026/10/29に追加した10項目）

**過去問の回を足す**：配布元に新しい回が載ったら、`index.html` の `KAI` の先頭に足す。

**更新情報**：画面の「更新情報」は `index.html` の `UPDATES`（新しいものを先頭に）。

## 動作確認

Playwright が入った環境で次を実行します。主な画面をPC幅（8問で回答）とスマホ幅（4問で回答）でひと通り操作し、エラーと主な動きを確かめます。

```bash
node tools/smoke-test.js
```

フォルダを渡すと、各画面のスクリーンショットを保存します（見た目の変化を比べるとき用）。

```bash
node tools/smoke-test.js shots
```

外部のフォント・CDN は読み込まずに確かめます。本人用（claude.ai の保存領域）と、PDF・PNG の出力は確かめません。
